Syntax reference & what the checker supports

Operands

$5 immediate · %eax register · A named memory

(%edx) indirect · -4(%ebp) displacement · 8(%edx,%ecx,4) base + index × scale + displacement

Registers: eax, ebx, ecx, edx, esi, edi, ebp, esp. Prefix them with %.

Instructions

mov, lea, add, sub, imul (two or three operands), cmp, test, and, or, xor, neg, inc, dec, not, nop.

jmp; je/jz; jne/jnz; jg, jge, jl, jle; js, jns; jo, jno; ja, jae, jb, jbe and their usual aliases.

Use the l suffix or no suffix. 8-, 16-, and 64-bit operations, shifts, calls, stack push/pop, directives, and system calls are outside this lab's subset.

cmp source, destination sets flags from destination − source. Arithmetic updates flags too; mov and lea preserve them. Symbols and labels are case-sensitive. Use # or // for comments; a semicolon separates instructions.

Checks execute up to 10,000 instructions per case. Passing means the listed cases match; it is not a proof for every possible input or a full C compiler. Assembly arithmetic wraps to 32 bits; ordinary C signed overflow is undefined, so the C exercises avoid it.
