Syntax reference & what the checker supports
          
Operands
$5 immediate · %eax register · A named memory
(%edx) indirect · -4(%ebp) displacement · 8(%edx,%ecx,4) base + index × scale + displacement
Registers: RAX, RBX, RCX, RDX, RSI, RDI, RBP, RSP and R8–R15, with 32-, 16- and 8-bit aliases (for example EAX/AX/AL, R8D/R8W/R8B). Use lowercase or uppercase with a % prefix.

            
Instructions
mov, lea, add, sub, imul (two or three operands), cmp, test, and, or, xor, neg, inc, dec, not, nop; shl/sal, shr, sar; pushq, popq, call, ret, leave.
jmp; je/jz; jne/jnz; jg, jge, jl, jle; js, jns; jo, jno; ja, jae, jb, jbe and their usual aliases.
Use b/w/l/q for 8/16/32/64-bit data. No suffix infers a register width, or defaults to 32 bits for legacy memory-only exercises. PUSH/POP always use the 64-bit stack here. Shifts accept $0..$255 or %cl. Calls and jumps require local labels. Directives, indirect calls, division, floating-point/SIMD, sign/zero-extension instructions and system calls are outside this bounded subset.

          
cmp source, destination sets flags from destination − source. Arithmetic updates flags too; mov and lea preserve them. Symbols and labels are case-sensitive. Use # or // for comments; a semicolon separates instructions.

          
Checks execute up to 10,000 instructions per case. Passing means the listed cases match; it is not a proof for every possible input or a full C compiler. Assembly arithmetic wraps to the selected operand width; ordinary C signed overflow is undefined, so the C exercises avoid it.

The slides contain two jump-description typos: jne branches when ZF is 0, and jge means signed greater than or equal. The checker follows the documented x86 semantics.
Lecture 10 corrections are explained in the lessons: slide 20’s load mapping, slide 33’s mismatched arithmetic, and slide 35’s mixed-width address. The simulator uses exact 64-bit integers but bounded memory, a 4096-byte stack, and symbolic code locations. No native code is executed.
