Explanations added between the source topics

Explicit notation practice, base-case testing, soundness and completeness, full program trees, FIRST/FOLLOW sets, left-recursion removal, ambiguity and precedence, detailed state-pair grammar construction, and cumulative transfer problems make the learning path self-contained. The relevant lessons label parsing extensions and distinguish them from the source material.

Conventions used consistently

  • Pattern 1 means independent composition. Pattern 2 means dependent nesting, following the design slides.
  • ε denotes the empty string; it is not an alphabet symbol. ∅ denotes the empty set.
  • Written stack strings put the top at the left. Literal single-symbol pushes occur in the reverse order of a written replacement string.
  • An ε-input transition does not test that input has ended. Deterministic empty-stack examples use an explicitly declared end marker; final-state examples use their stated convention.
  • Grammar derivation traces use one fixed input throughout. LR parsing reconstructs a rightmost derivation in reverse.
  • Pumping proofs cover every legal decomposition, including empty pumping pieces. The exponent may depend on the case.
