      How this recall system works
      Focused: keep a topic cue while you learn the rule. Work through facts and syntax first, then add connected traces and methods.
      Mixed: choose the relevant concept yourself. Topic labels appear after your attempt. The stated C assumptions remain visible.
      Due review: return to skills you have already attempted when their review time arrives. A different prompt may test the same skill; fresh skills are not added to fill the round.
      Hints, opened references, and revealed answers are recorded. Automatically checked answers and rubric self-checks are reported separately. A blank-page method is a self-check, never an automatic code grade.
      Progress is saved only in this browser when available. Export a backup to move it to another browser.
