Scope and language reference
This drill covers the C forms used across the current 2122 foundations, recall and midterm practice: variables, expressions, control flow, functions, pointers, arrays, strings, standard I/O, memory, structures, byte operations, headers and build commands. Each question supplies its own context.
Several choices may be valid C in another context. Choose the form that fulfills the exact request. A miss does not necessarily mean the chosen text could never compile.
Language reference: WG14 C committee draft for the language and library rules used here; build-command reference: GCC compilation options.
