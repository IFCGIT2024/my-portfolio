## Pipeline Scripts (run in this order)

| File | Purpose | Status | Run when |
|---|---|---|---|
| `crawl_forsale_urls.py` | Crawls viewpoint.ca/forsale → all subdistricts → all streets → collects all cutsheet URLs. Outputs `forsale_urls.csv`. Supports resume. | **Done — 7,519 URLs collected** | Re-run weekly to refresh listing inventory |
| `scrape_properties.py` | Reads `forsale_urls.csv`, scrapes full property detail per listing (HTML + 3 APIs). Outputs `properties.csv`, `assessments.csv`, `mls_history.csv`. Supports resume. | **In progress — ~1,400/6,381 done** | After crawl completes |
| `load_db.py` | Loads the 3 CSVs into `properties.sqlite` with proper types, schema, and indexes. | **Ready — not yet run** | After scrape finishes |
| `score.py` | Reads `properties.sqlite`, computes `deal_score`, `confidence_score`, `score_reason_breakdown`, `segment_tags`, and derived metrics for every property. Writes `scores` table. | **Ready — not yet run** | After load_db.py |
| `export_top_deals.py` | Exports top 500 deals + summary stats to `dashboard/deals.json` and `dashboard/stats.json`. | **Ready — not yet run** | After score.py |

## Output Data Files

| File | Description | Rows (approx) |
|---|---|---|
| `forsale_urls.csv` | All current forsale cutsheet URLs. Columns: `subdistrict_id, subdistrict_url, street_url, cutsheet_url` | 7,519 |
| `properties.csv` | One row per property. 59 columns: address, price, beds, baths, sqft, age, construction, zoning, tax, assessment, views, MLS history refs, etc. | ~6,381 when done |
| `assessments.csv` | Assessment history rows. Columns: `cutsheet_url, pid, year, assessment, taxes` | Many per property (19yr history) |
| `mls_history.csv` | MLS listing history rows. Columns: `cutsheet_url, pid, listing_id, class_id, ldate, sdate, expdate, dom, lprice, sprice, stid` | Varies |
| `properties.sqlite` | SQLite DB with tables: `properties`, `assessments`, `mls_history`, `scores`. Built by load_db.py + score.py | — |

| File | Description |
|---|---|

## Scoring Quick Reference (v1)

```
+30  bank_owned
+20  relist 3+ times
+10  relist 2 times
+15  DOM > 90 days
+10  DOM > 60 days
+15  price dropped >10% from original list
+10  price dropped >5%
+30  listed below 85% of assessment
+20  listed below 95% of assessment
+10  assessment rising >8%/yr
+15  views > 500
+10  views > 200
+5   views/DOM > 5
+10  waterfront
-15  age > 80 yrs + stone foundation
-5   private well
-5   septic
cap  0–100
```

Confidence score (0–100) deducts 7pts per null key field — high score + low confidence = do not trust without verification.
